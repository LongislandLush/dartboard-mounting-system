# Dartboard Mounting System (DMS)

A modular wall-mounted dartboard system designed using SolidWorks, featuring a Japanese Hinoki wood backboard, birch plywood connectors, EVA cushioning, and adjustable 3D-printed brackets.

**Project Status:** CAD Prototype — Physical Validation Pending

## Specifications

| Item | Specification |
|---|---|
| CAD Software | SolidWorks |
| Backboard Dimensions | 720 × 600 mm |
| Backboard Material | Japanese Hinoki Wood |
| Backboard Construction | 8 modular wooden panels |
| Connector Material | Birch Plywood |
| Cushioning | EVA Foam |
| Dartboard | Decathlon ED110 |
| CAD Assembly Mass | 4.202 kg |
| Mounting Hardware | D-Ring Hangers and 3M Command Products |
| Adjustable Supports | 3D-Printed Z-Brackets with M3 Heat-Set Inserts |

## Design Features

- Modular eight-panel wooden backboard
- Birch plywood reinforcement and mounting plates
- 10 mm EVA protective surround
- 2 mm EVA cushioning pads
- D-ring hanging hardware
- Adjustable 3D-printed Z-brackets
- SolidWorks exploded assembly and Bill of Materials

## Validation Status

The CAD assembly and initial mechanical layout have been completed.

The wall-mounting system, adhesive attachment, screw engagement, load distribution, and resistance to repeated dart impacts and removal forces have not yet been physically validated.

The current CAD mass is based on assigned material properties and an overridden mass for the simplified ED110 model.

**This design is a prototype and is not yet approved for installation or load-bearing use.**
